# Phase 1A Gate Report

P1-A is canonical protocol and runtime integrity. P1-B is behavioral
observability with a valid locked dataset and outcome-specific coverage. P1-C is
paired comparability and complete five-role/AB-BA balance. P1-D is
`PENDING_HUMAN_VALIDATION` until independent human labels, empirical reliability
and adjudication are complete; it does not require a significance result.

Gate statuses are re-derived from source records. A mock can pass engineering
contracts but cannot pass live calibration or scientific validation. Phase 1B is
`INACTIVE` until P1-A/B/C pass, P1-D becomes `CONFIRMATORY_READY`, and the
Phase 1A closure state is explicitly recorded.

# WP03 — Workshop and report workflow

Status: `AWAITING_INTEGRATION` / `PENDING_SCIENTIFIC_APPROVAL`.

WP03 will define the workshop and report workflow consumed by the core runtime:
the six public rounds, t0/t6/tR checkpoints, report draft, independent reviews,
and revision stages. It consumes WP01's agenda, prompts, report policy and
decision status without selecting a provider or deployment. No WP03 runtime is
implemented here.

Model-provider integration and adapter invocation belong to WP02. WP03 must not
duplicate provider routing or change the WP01 study matrix and prompt semantics.

STEP 01 / THE IDEA

AGORA is a mirror, not an automation product.

AGORA builds artificial social worlds where agents interact under explicit roles, rules, and incentives. The purpose is to observe what emerges between them — coordination, conformity, gaming, collusion, dissent — and to use those traces to question the institutions that shape human knowledge.

The first workshop is a contained experiment. The larger program extends the same method to academic publishing and peer review.

STEP 02 / THE WORKSHOP

Put agents together. Change one condition. Watch what happens.

The Reimagining Humans workshop gives agents roles and a shared problem, then lets them exchange proposals and respond to one another. The pilot varies the pressure to produce a joint report and the composition of the group.

A control condition lets behavior emerge with less moderation. Replay tests hide speaker identity or endorsements to determine whether ideas are judged differently when social context changes.

STEP 03 / THE EVIDENCE

If the trace is not auditable, the experiment cannot teach us much.

AGORA is built as a research instrument. The system separates orchestration, model adapters, and immutable evidence storage. Runs need enough structure to reconstruct what each participant received, produced, and changed.

The implementation also distinguishes an agent refusing a task from an infrastructure failure. Without that distinction, a broken API could be misread as meaningful agent behavior.

STEP 04 / THE RESEARCH PROGRAM

The workshop is one experiment inside a larger institutional question.

Beyond the workshop, AGORA asks how scientific institutions shape judgment: what gets reviewed, rewarded, published, cited, or ignored. Simulated publishing worlds make it possible to change one institutional rule and compare the consequences.

The aim is not to claim that agents perfectly reproduce humans. It is to build controlled counterfactuals that reveal assumptions, expose feedback loops, and generate better questions about real institutions.

The problem

Two different worlds. The same transcript.

World A The agent read the discussion, weighed in, and chose to hold back. turn 14 — no message
vs
World B The request timed out. The agent was never asked. Nobody noticed. turn 14 — no message

One is a finding. The other is a bug. They leave behind the exact same empty space.

If you cannot tell them apart, every result you publish is contestable — and the first reviewer to ask “how do you know it wasn’t just broken?” is right to ask.

Talk trackThis is the whole reason the project exists. If Leo only absorbs one slide, make it this one.
The decision

So we didn’t study behaviour. Not yet.

First we built something that can tell those two worlds apart — and then spent this phase proving that it can.

That is the entire claim of Phase 0. It is a claim about the instrument, not about artificial intelligence. Nothing here says agents deliberate, persuade or cooperate. It says that when we later ask those questions, the answers will be trustworthy.

Measure the ruler before you measure with it.

Talk trackSay plainly that this phase makes no AI claim. Volunteering that upfront is what buys credibility for everything after.
The instrument

Five agents, one moderator, one bounded conversation

They talk in public and in small breakout groups. Around that conversation sit three rules.

It writes everything down

Every message, every attempt, every retry, every failure — and exactly what each agent could see at the moment it answered.

It freezes the setup

The model, prompts, budgets and rules are locked and fingerprinted before the run starts. Change one setting and the fingerprint changes with it.

It never guesses

A failure is stored as a failure. It is never quietly folded in as something the agent chose to do.

Talk trackThree ideas, no jargon. If someone wants the 30 named thresholds underneath, that is a follow-up document, not this room.
The test

Then we broke it on purpose

A system that has never failed cannot prove it handles failure. So we injected five real faults into a live run and watched what the record said.

TimeoutThe model never answered in time
Rate limitThe provider refused, temporarily
Provider errorThe service returned an error
Corrupted replyThe response came back malformed
Broken toolA tool the agent used stopped responding

How we knew before that

None of that was the first test

Before any real model was involved, the whole machine was driven by controlled stand-ins — providers that imitate a model’s interface without calling one.

That is not a shortcut. A real model gives a different answer every time, so when something goes wrong you cannot tell whether the plumbing broke or the model simply felt different today. Remove the model’s variability and any failure left is the instrument’s fault — which is exactly what we were trying to find.

Stand-in one · deterministic Drives routing, storage, retries and injected faults with answers that never vary. proves: the system classifies, records and recovers from failure
and
Stand-in two · context contract Answers with a cryptographic receipt of exactly what it was shown. proves: each agent received precisely the material it was entitled to

And the hard limit: no result from a stand-in is evidence about how a model behaves. That is the entire reason the closing evidence had to run on a real one.

Talk trackThe second stand-in is the clever one — it makes “the agent saw exactly this and nothing more” a checkable fact instead of a design intention.
The testing rule

A check that cannot fail is not evidence

Every single acceptance check is tested twice: once on a run that should satisfy it, and once on that same run after deliberately damaging one stored record.

If the check still passes on the damaged run, it was never really checking anything. That rule caught real defects during review — measures that reported success no matter what they were shown.

The limits

What this still does not let us say

Nothing about how agents behave

Whether they deliberate, persuade, form coalitions or converge is untouched. The instrument was not built to answer that — only to make the answer trustworthy later.

Nothing about meaning

We prove a summary faithfully points at the messages it came from. We do not yet prove it preserves what they meant. That needs human review.

One provider, one model

A second provider is a separate replication, still to run.

Not yet institutionally approved

The written protocol is still a draft. Formal sign-off is outstanding.

Talk trackDon’t rush these. Naming your own limits before anyone asks is what makes the earlier numbers land as honest.

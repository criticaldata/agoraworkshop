# Phase 1A Coding Codebook

`role_criterion`: score 0 absent/contrary, 1 partial, 2 clear, or
`not_assessable` when evidence is inadequate.

`interaction_contingency`: present only when the source message depends on an
earlier exposed peer argument; otherwise absent only after the complete eligible
follow-up set has been reviewed. `relation` is one of supports, challenges,
extends, rejects or revises.

`behavioral_zero` is a valid observed no-op/abstention where the agent had a
behaviorally available opportunity. `infrastructure_missing` covers provider,
tool, timeout, budget, deadline, cancellation or restart failure.
`measurement_missing` covers invalid/unavailable probes. `annotation_missing`
covers absent or unresolved human coding. None of these states is silently
re-coded as zero.

# Phase 1A Calibration Report Contract

This report is generated only after baseline, identical rerun, and linked fault
evidence exist under one frozen manifest. It must report run IDs, config hashes,
provider/model/deployment provenance, available paired blocks, RF/ICR
distribution, alpha by stratum, missingness, reviewer burden, contamination
checks, and the paired-RF variance used for precision planning.

No live run IDs, alpha values, sample-size recommendation or scientific PASS is
filled from a mock. If the endpoint is unavailable the exact state is
`BLOCKED_EXTERNAL_LIVE_PROVIDER` and the launch package remains the next action.
